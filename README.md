# Практическая работа — Калькулятор квадратных уравнений (Neon Edition)

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Интерактивный калькулятор для решения квадратных уравнений вида `ax² + bx + c = 0`.
Проект выполнен с упором на уникальный современный дизайн (Dark Theme / Glassmorphism / Neon) без использования стандартных CSS-фреймворков (Bootstrap и т.д.).

## Что реализовано
- **Ввод коэффициентов:** три поля для ввода значений `a`, `b`, `c` с поддержкой десятичных чисел.
- **Валидация данных:**
  - проверка на пустые поля;
  - защита от ввода нечисловых значений (`isNaN`);
  - проверка условия `a ≠ 0` (иначе уравнение не является квадратным).
- **Математическая логика:**
  - вычисление дискриминанта по формуле `D = b² - 4ac`;
  - нахождение двух корней при `D > 0`;
  - нахождение одного корня при `D = 0`;
  - вывод сообщения об отсутствии действительных корней при `D < 0`;
  - округление результатов до 4 знаков после запятой (`toFixed(4)`) для аккуратного вывода.
- **Визуализация состояний:**
  - результат плавно выезжает снизу (`transform`, `opacity`);
  - цвет текста меняется в зависимости от результата (зелёный — успех, оранжевый — один корень или предупреждение, красный — ошибка или нет корней).
- **Современный UI/UX:**
  - тёмный фон с неоновыми градиентными пятнами (фиолетовый и голубой);
  - стеклянный эффект (`backdrop-filter: blur`);
  - шрифты `Inter` (для интерфейса) и `JetBrains Mono` (для формул и цифр);
  - кастомные инпуты (без стандартных стрелочек браузера), кнопка с hover-эффектом и тенью.

## Технологии
- HTML5
- CSS3 (CSS-переменные, градиенты, `backdrop-filter`, `@keyframes`, Flexbox)
- JavaScript (ES6, DOM, `Math.sqrt`, `parseFloat`, `isNaN`)

## Файлы
- `index.html` — разметка интерфейса;
- `style.css` — стилизация (тёмная неоновая тема);
- `script.js` — логика расчёта и валидации.
